# Sample Superstore Sales Analysis | Tableau Dashboard

## Project Overview

This project presents an interactive **Sample Superstore Sales Dashboard** developed using Tableau.

The dashboard provides insights into sales performance, profitability, product performance, customer sales, and regional distribution. It helps explore business performance across different categories, regions, and shipping modes.

## Dashboard Preview

![Sample Superstore Sales Dashboard](Superstore%20Sales%20Dashboard.png)

## Key Dashboard Features

The dashboard includes the following visualizations:

1. **Sales Analysis:** Visualizes sales performance across the displayed data points.
2. **Profit Analysis:** Tracks profit performance and highlights variations.
3. **State-Wise Profit:** Displays profit distribution across different US states.
4. **Top 10 Products:** Identifies products ranked by profit.
5. **Distribution of Sales:** Compares category-wise sales distribution across regions.
6. **Top N Customer Sales:** Highlights customers contributing to sales.

## Dashboard Filters

The dashboard provides interactive filters for:

- Region
- Ship Mode
- Category

These filters allow users to explore the dashboard from different business perspectives.

## Dataset Description

The project uses the **Sample - Superstore.xls** dataset.

The dataset contains 9,994 records and 21 columns, covering information such as:

- Order and customer details
- Product categories and sub-categories
- Sales and profit
- Quantity and discount
- Region and state
- Shipping mode

## Key Business Insights

- Profitability varies across different states.
- Product-level profit analysis helps identify high-performing products.
- Sales distribution differs across regions and product categories.
- Customer-level sales analysis highlights important contributors to revenue.
- Interactive filters make it easier to explore regional and category-level performance.

## Conclusion

This project demonstrates how Tableau can transform retail sales data into an interactive business dashboard. It provides a visual overview of sales, profit, product performance, customer sales, and regional distribution to support data-driven business analysis.
